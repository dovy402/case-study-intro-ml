Judul Studi Kasus

Prediksi Kelayakan Beasiswa atau Status Mahasiswa Menggunakan Algoritma Klasifikasi Machine Learning (Scikit-Learn)

Skenario & Latar Belakang

Di dunia akademik dan industri, Machine Learning sering digunakan untuk melakukan klasifikasi otomatis (misalnya memprediksi apakah seorang kandidat layak menerima beasiswa atau apakah sebuah sistem mengalami anomali). Dalam studi kasus ini, kita akan membuat model Machine Learning sederhana menggunakan pustaka Scikit-Learn.
